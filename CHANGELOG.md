## 0.2.0

Solana payments and dual-wallet support.

- Pay Solana x402 services with USDC or $THREE through the real `@x402/svm` exact scheme.
- Store independent Solana and EVM keys in VS Code SecretStorage.
- Select the correct payment rail from each endpoint's 402 challenge automatically.
- Prefer Solana USDC, Base USDC, or $THREE with the new `x402.preferToken` setting.
- Display the selected token, network, paying address, and settlement receipt before and after each call.
- Add commands to set, replace, and clear either wallet key.
